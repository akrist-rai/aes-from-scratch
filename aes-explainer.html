What is AES?
Block size, key variants, the state matrix
FIPS 197 Symmetric
▼

AES is a symmetric block cipher standardised by NIST in 2001. It processes exactly 128-bit (16-byte) blocks and supports three key sizes, each giving a different number of rounds.

Key Sizes & Rounds

VariantKey bitsNkRounds
AES-128128410
AES-192192612
AES-256256814

Every round applies (except last)

SubBytes ShiftRows MixColumns AddRoundKey

The final round omits MixColumns — this makes encryption and decryption structurally symmetric so the same key schedule works in reverse.

The State — a 4×4 Byte Matrix

The Mathematics — GF(2⁸)
Galois field arithmetic, xtime, gmul, the S-Box
GF(2⁸) Interactive
▼

AES arithmetic lives in GF(2⁸) — a Galois Field with 256 elements where every byte is a polynomial of degree ≤ 7 with binary coefficients.

Bytes as Polynomials

byte → polynomial
0x53 = 0101 0011₂
= x⁶ + x⁴ + x + 1
GF(2⁸) addition = XOR
0x53 XOR 0x83
= 0101 0011
⊕ 1000 0011
= 1101 0000 = 0xD0

Irreducible Polynomial

Multiplication can yield degree ≥ 8; we reduce modulo AES's irreducible polynomial:

AES reduction polynomial
m(x) = x⁸ + x⁴ + x³ + x + 1 = 0x11B (hex)

xtime — Multiply by 2 in GF(2⁸)

Left-shift by 1. If bit 7 was set, XOR with 0x1B (the low byte of 0x11B) to reduce:

func xtime(b byte) byte {
    if b & 0x80 != 0 {
        return (b << 1) ^ 0x1b
    }
    return b << 1
}

xtime(0x57)

0x57 = 0101 0111
bit 7 = 0 → shift only
→ 1010 1110 = 0xAE

xtime(0xAE):
bit 7 = 1 → shift + XOR 0x1B
0101 1100 ⊕ 0001 1011 = 0x47

gmul — General GF(2⁸) Multiplication

Russian Peasant algorithm: iterate over bits of b, doubling a via xtime each step:

func gmul(a, b byte) byte {
    var p byte
    for i := 0; i < 8; i++ {
        if b & 1 != 0 { p ^= a }   // if bit set, add a to accumulator
        a = xtime(a)              // double a
        b >>= 1
    }
    return p
}

The S-Box

Each byte is first inverted in GF(2⁸) (0x00 maps to itself), then an affine transform (8×8 bit matrix + XOR 0x63) is applied. The result is hardcoded as a 256-entry lookup table providing maximal nonlinearity.

🔬

The S-box has no fixed points (no byte maps to itself), maximum nonlinearity (resistance to linear cryptanalysis), and zero correlation with the identity function — all by design.

Key Expansion — the Key Schedule
rotWord, subWord, Rcon — live 11-round key table
Interactive
▼

From a 128-bit key, AES derives 11 round keys × 16 bytes = 176 bytes. The key is viewed as Nk 4-byte words; each subsequent word is derived from the one before.

rotWord

Left-rotate by 1 byte
[a₀,a₁,a₂,a₃] → [a₁,a₂,a₃,a₀]

subWord

Apply S-Box to each byte
[a₀,a₁,a₂,a₃] → [S(a₀),S(a₁),S(a₂),S(a₃)]

Round Constants (Rcon)

Rcon[i] = xtime^(i-1)(0x01) — powers of 2 in GF(2⁸)
{ 0x01, 0x02, 0x04, 0x08, 0x10, 0x20, 0x40, 0x80, 0x1B, 0x36, 0x6C } 
for i := Nk; i < totalWords; i++ {
    tmp := w[i-1]
    if i % Nk == 0 {
        tmp = subWord(rotWord(tmp))
        tmp[0] ^= rcon[i/Nk - 1]  // inject round constant
    } else if Nk > 6 && i%Nk == 4 {
        tmp = subWord(tmp)           // AES-256 extra step
    }
    w[i] = xorWords(w[i-Nk], tmp)
}

ECB — Electronic Codebook
CBC — Cipher Block Chaining
CTR — Counter Mode

The simplest mode: each 16-byte block is encrypted independently with the same key. No chaining. No IV.

ECB encrypt / decrypt
C[i] = AES_K( P[i] )
P[i] = AES_K⁻¹( C[i] )
⛔

ECB is cryptographically broken. Identical plaintext blocks always produce identical ciphertext blocks — an attacker can detect repeated data without the key. Never use ECB for real data.

ECB Weakness — Identical Blocks

Each plaintext block is XORed with the previous ciphertext block before encryption. The first block uses a random IV.

CBC encrypt
C[0] = AES_K( P[0] ⊕ IV )
C[i] = AES_K( P[i] ⊕ C[i-1] )
CBC decrypt
P[0] = AES_K⁻¹(C[0]) ⊕ IV
P[i] = AES_K⁻¹(C[i]) ⊕ C[i-1]
✅

Identical plaintext blocks produce different ciphertext. The IV is public (sent alongside ciphertext); only the key is secret.

⚠️

Encryption is sequential — each block needs the previous ciphertext. Decryption can be parallelized since all ciphertext blocks are already available.

CBCEncrypt 
func (c *Cipher) CBCEncrypt(pt []byte) ([]byte, error) {
    iv := make([]byte, BlockSize)
    io.ReadFull(rand.Reader, iv)
    padded := pkcs7Pad(pt, BlockSize)
    out := make([]byte, BlockSize+len(padded))
    copy(out, iv)
    prev := iv
    for i := 0; i < len(padded); i += BlockSize {
        block := out[BlockSize+i : BlockSize+i+BlockSize]
        copy(block, padded[i:i+BlockSize])
        xorBlock(block, prev)
        c.Encrypt(block)
        prev = block
    }
    return out, nil
}

CTR turns AES into a stream cipher. It encrypts an incrementing counter to produce a keystream, then XORs with plaintext. Encrypt and decrypt are identical operations.

CTR — same for enc & dec
keystream[i] = AES_K( nonce ‖ counter_i )
C[i] = P[i] ⊕ keystream[i]
✅

No padding needed. Fully parallelizable in both directions. Supports random access — decrypt block N without decrypting 0..N-1.

⛔

The nonce must never be reused with the same key. Nonce reuse lets an attacker XOR two ciphertexts to cancel the keystream — catastrophic.

Go code

CTRCrypt 
func (c *Cipher) CTRCrypt(
    data []byte, encrypt bool,
) ([]byte, error) {
    var nonce, payload []byte
    if encrypt {
        nonce = make([]byte, BlockSize)
        io.ReadFull(rand.Reader, nonce)
        payload = data
    } else {
        nonce, payload = data[:BlockSize], data[BlockSize:]
    }
    out := make([]byte, len(payload))
    ctr := make([]byte, BlockSize)
    copy(ctr, nonce)
    ks := make([]byte, BlockSize)
    for i := 0; i < len(payload); i += BlockSize {
        copy(ks, ctr)
        c.Encrypt(ks)
        incrementCounter(ctr)
        for j := i; j < min(i+BlockSize,len(payload)); j++ {
            out[j] = payload[j] ^ ks[j-i]
        }
    }
    if encrypt { return append(nonce, out...), nil }
    return out, nil
}

Cipher struct & constructor

type Cipher struct {
    keys   [][][4]byte  // [round][col][byte] — Nr+1 round keys
    rounds int
}

func NewCipher(key []byte) (*Cipher, error) {
    switch len(key) {
    case 16, 24, 32:
    default: return nil, errors.New("aes: key must be 16, 24, or 32 bytes")
    }
    c := &Cipher{}
    c.keys = keyExpansion(key)
    c.rounds = len(c.keys) - 1
    return c, nil
}

encryptState — the main loop

func encryptState(s state, keys [][][4]byte, rounds int) state {
    s = addRoundKey(s, keys[0])
    for r := 1; r < rounds; r++ {
        s = subBytes(s)
        s = shiftRows(s)
        s = mixColumns(s)
        s = addRoundKey(s, keys[r])
    }
    s = subBytes(s)   // final round — no MixColumns
    s = shiftRows(s)
    s = addRoundKey(s, keys[rounds])
    return s
}

MixColumns — GF(2⁸) matrix multiply

func mixColumns(s state) state {
    for col := 0; col < 4; col++ {
        a,b,c,d := s[0][col],s[1][col],s[2][col],s[3][col]
        s[0][col] = gmul(2,a)^gmul(3,b)^c        ^d
        s[1][col] = a       ^gmul(2,b)^gmul(3,c)^d
        s[2][col] = a       ^b        ^gmul(2,c)^gmul(3,d)
        s[3][col] = gmul(3,a)^b        ^c        ^gmul(2,d)
    }
    return s
}
// Matrix: [ 2 3 1 1 ]  Multiplication is gmul(), addition is XOR
//         [ 1 2 3 1 ]
//         [ 1 1 2 3 ]
//         [ 3 1 1 2 ]

PKCS#7 Padding

func pkcs7Pad(data []byte, bs int) []byte {
    pad := bs - len(data)%bs   // always 1..bs, never 0
    padded := make([]byte, len(data)+pad)
    copy(padded, data)
    for i := len(data); i < len(padded); i++ {
        padded[i] = byte(pad)
    }
    return padded
}
Example: 13-byte input padded to 16 bytes
48 65 6c 6c 6f 20 57 6f 72 6c 64 21 0a
→ 48 65 6c 6c 6f 20 57 6f 72 6c 64 21 0a 03 03 03
(3 bytes of padding, each with value 0x03)

Counter Increment

func incrementCounter(c []byte) {
    for i := len(c) - 1; i >= 0; i-- {
        c[i]++
        if c[i] != 0 { break }  // no carry — done
    }
}

Big-endian increment: start from the rightmost byte and propagate carry leftward. Wraps safely back to zero after 2¹²⁸ blocks.

func main() {
    // ── AES-128 single block (FIPS 197 Appendix B vector)
    key128, _ := hex.DecodeString("000102030405060708090a0b0c0d0e0f")
    pt, _      := hex.DecodeString("00112233445566778899aabbccddeeff")
    c128, _   := aes.NewCipher(key128)
    block     := make([]byte, 16)
    copy(block, pt)
    c128.Encrypt(block)  // → 69c4e0d86a7b04300d8a8bb...  (FIPS expected)
    c128.Decrypt(block)  // → 00112233445566778899aabbccddeeff

    // ── AES-256 CBC — arbitrary length, padding automatic
    key256, _ := hex.DecodeString("000102030405060708090a0b0c0d0e0f" +
                                   "101112131415161718191a1b1c1d1e1f")
    c256, _   := aes.NewCipher(key256)
    ct, _     := c256.CBCEncrypt([]byte("The quick brown fox..."))
    pt2, _    := c256.CBCDecrypt(ct)  // ct = IV || ciphertext

    // ── AES-192 CTR — no padding, enc == dec
    key192, _ := hex.DecodeString("000102030405060708090a0b0c0d0e0f1011121314151617")
    c192, _   := aes.NewCipher(key192)
    enc, _    := c192.CTRCrypt(plaintext, true)   // → nonce || ciphertext
    dec, _    := c192.CTRCrypt(enc, false)         // → original plaintext

    // ── ECB weakness: identical plaintext → identical ciphertext
    rep := []byte("YELLOW SUBMARINEYELLOW SUBMARINE")
    ecb, _ := c128.ECBEncrypt(rep)
    // ecb[0:16] == ecb[16:32] — blocks identical, structure exposed!
    _ = pt2; _ = dec
}
